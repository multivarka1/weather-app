# Atmos

Atmos — приложение прогноза погоды для iOS 18 и новее. Прогнозы получает от MET Norway через собственный Cloudflare Worker. Клиент использует SwiftUI, CoreLocation, MapKit, URLSession и локальный кэш. Для сборки требуется Xcode 26 или новее.

## Запуск

1. Разверните прокси по инструкции в [proxy/README.md](proxy/README.md) и укажите настоящий контактный email разработчика для User-Agent.
2. Откройте `Atmos.xcodeproj` в Xcode, выберите общую схему Atmos и симулятор iPhone с iOS 18 или новее.
3. Соберите и запустите приложение. В настройках приложения укажите HTTPS-адрес развёрнутого Worker, затем выберите город или разрешите геолокацию и обновите прогноз.

Без настроенного прокси прогноз не загружается. Для запуска на собственном устройстве необходима настройка подписи в Xcode.

## Устройство приложения

`Atmos/Models` содержит модели ответа и суточную агрегацию по часовому поясу города. `Services` содержит сетевой клиент, геолокацию и кэш UserDefaults. `WeatherViewModel` управляет выбранным городом и состояниями загрузки. `Views` и `Components` содержат интерфейс. Город, настройки и последний полученный прогноз сохраняются локально. При ошибке загрузки отображается сохранённый прогноз с временем его сохранения.

На iOS 26 применяется `glassEffect`, на iOS 18–25 используется системный материал. При включённом Reduce Transparency используются непрозрачные поверхности. Отдельные значения, отсутствующие в ответе MET Norway, не отображаются. Температурные максимумы и минимумы рассчитываются по имеющимся точкам прогноза за соответствующие сутки и могут относиться к неполному дню.

## GitHub Actions

Workflow `.github/workflows/ios.yml` запускается при push в `main` и вручную через Actions → iOS → Run workflow. Он выбирает Xcode 26 на macOS runner, запускает тесты на доступном симуляторе без подписи и загружает `Atmos-simulator.zip` как артефакт. Архив содержит сборку для симулятора, а не устанавливаемый IPA. Доступность Xcode 26 на выбранном runner следует проверить в первом запуске.

Тесты проверяют декодирование, пустой прогноз, преобразование температуры и группировку по часовому поясу. Сборку и запуск тестов необходимо проверить на macOS с Xcode.

## Сборка для iPhone

В GitHub Actions можно вручную запустить `iOS device (unsigned)`. Артефакт `Atmos-device-unsigned` содержит приложение для iPhone без подписи и не устанавливается непосредственно на устройство. Для установки откройте проект на Mac в Xcode, подключите iPhone, выберите его в качестве устройства и в разделе Signing & Capabilities укажите свою команду Apple ID и уникальный Bundle Identifier. Затем запустите приложение кнопкой Run. Бесплатная личная команда Apple ID позволяет тестировать приложение на собственном устройстве с ограничениями Apple. Для распространения существуют отдельные требования Apple Developer Program.
