# Прокси Atmos

Cloudflare Worker пересылает запросы Locationforecast и использует заголовки кэширования MET Norway. Установите Wrangler, войдите в Cloudflare, выполните из этой папки `npx wrangler secret put MET_CONTACT` и укажите настоящий контактный email разработчика. Затем выполните `npx wrangler deploy`. Запросы отправляются на адрес Worker с параметрами `lat` и `lon`, например `?lat=59.9139&lon=10.7522`.

Проверьте действующие условия MET Norway перед публикацией. Бесплатный тариф Cloudflare имеет ограничения. Адрес Worker потребуется указать в настройках приложения, когда клиент будет реализован.
